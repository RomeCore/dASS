# Мета-тулы

Мета-тулы — это **динамические тулы, создаваемые самой LLM**, когда встроенного
набора не хватает. Они хранятся как скрипты `.lua` или `.py`.

## Как это работает

1. Вы просите ассистента создать тул для повторяющейся задачи.
2. Ассистент изучает API скриптования и пишет скрипт.
3. Скрипт регистрируется как тул и появляется в тулсете агента.

## Где они живут

Скрипты хранятся в `%LOCALAPPDATA%/LLMDesktopAssistant/metatools`.
Их можно редактировать вручную или делиться с другими.

## Пример

> [!TIP]
> Мета-тул может обернуть целый workflow: например, выполнить `git diff`, отправить
> его субагенту со специальным промптом и вернуть саммари — одним вызовом.

См. также: [Скриптование Lua](scripting.md), [Тулы](../tools.md).
