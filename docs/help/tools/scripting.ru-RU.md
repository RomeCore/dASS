# Скриптование

В dASS есть два движка скриптования, доступные модели:

| Движок | Расширение | Описание |
|---|---|---|
| **AsyncLua** | `.lua` | Интерпретатор Lua с async/await и широким API |
| **Python** | `.py` | Python в настроенном `.venv` или глобальном окружении |

## Стриминг результатов

Долгие скрипты могут стримить вывод, показывать статус-иконки и прогресс-бары
через API `dass.tool.result` — UI отображает их вживую.

> [!NOTE]
> Скрипты выполняются в отдельном процессе/песочнице, где это возможно, и всегда
> проходят тот же пайплайн одобрения, что и любой другой тул.
