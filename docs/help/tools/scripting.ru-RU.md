# Скриптование

Скриптовый аддон - это **один файл** в аддон-паке. Папка решает, чем он станет, расширение - на каком языке:

| Папка | Чем становится файл |
|---|---|
| `tools/` | тул, который модель может вызвать |
| `commands/` | слэш-команда `/имя`, которую запускаете вы сами |
| `context/` | prompt-контекст, добавляемый в каждый запрос |

| Язык | Расширения | Блок фронтматтера | Где работает |
|---|---|---|---|
| Lua | `.lua`, `.alua` | `--[[` … `]]` | любая сборка, внутри процесса |
| Python | `.py` | `"""` … `"""` | сборка Desktop, отдельный процесс |
| Bash | `.sh` | `#---` … `#---` | сборка Desktop, нужен bash (на Windows - Git Bash) |
| PowerShell | `.ps1` | `#---` … `#---` | сборка Desktop, `pwsh` 7 или Windows PowerShell 5.1 |
| Batch | `.bat`, `.cmd` | `REM ---` … `REM ---` | только Windows |

У шелл-языков фронтматтер спрятан в настоящие комментарии, поэтому файл остаётся запускаемым как есть.

## Фронтматтер

```yaml
#---
#title: Count files
#description: Считает записи в папке и сообщает, сколько их.
#category: Filesystem
#argument-schema: |
#  {"type":"object","properties":{"path":{"type":"string"}},"required":["path"]}
#json-input: true
#---
```

| Ключ | Значение |
|---|---|
| `title`, `description`, `category` | отображаемые строки; описание читает модель, когда решает вызвать тул |
| `argument-schema` | JSON Schema **записанная YAML-строкой** (`\|`-блок или в кавычках): однострочный маппинг `{...}` строкой не является и будет проигнорирован |
| `behaviours` | чего касается тело; по этим флагам политика одобрения гейтит тул |
| `sync` | как тул блокирует файлы: `write`, `read` или `none` (по умолчанию выводится из `behaviours`) |
| `json-input` | `auto` (по умолчанию), `true` (JSON-строка) или `false` (нативная структура) |
| `json-output` | `true` (весь stdout - JSON) или `"<BEGIN>*<END>"` (захват между маркерами) |
| `run-terminal` | запускать скрипт в интерактивном терминале вместо управляемого процесса |
| `wait` | вместе с `run-terminal`: ждать ли завершения скрипта (по умолчанию `true`) |
| `timeout` | бюджет prompt-контекста в миллисекундах (по умолчанию 2000, предел 10000) |

`json-input: false` на языке, который не умеет передавать структуру (Bash, Batch), отклоняется при загрузке.

## Что получает тело

Имена переменных принадлежат виду аддона:

| Вид | Переменная | По умолчанию | С `json-input: true` |
|---|---|---|---|
| Тул | `tool_args` | таблица Lua, словарь Python, `PSCustomObject` в PowerShell; Bash и Batch всегда получают JSON-текст | JSON-текст |
| Команда | `command_args` | то же самое, внутри `{ positionals, keyed, rest, raw }` | JSON-текст |
| Контекст | `previous` | ранее вставленный текст или `nil`/`None`/`$null` | JSON-текст этого текста |

У Bash и Batch своей структуры нет, поэтому они всегда получают JSON-текст и разбирают его сами (`jq` или что есть
под рукой).

## Как скрипт отвечает

| Вид | Результат |
|---|---|
| Тул | всё напечатанное - результат; `json-output` дополнительно вынимает структуру из stdout |
| Команда | JSON-контракт `part`, `generate`, `effect`, `error` |
| Контекст | **stdout - это текст контекста**; ничего не напечатано - «контекста нет» |

> [!WARNING]
> Команда, написанная в JSON-форме тула (`status`/`result`/`structured`), не отрендерит **ничего**: `part` нет, а
> `generate: false` умеет только понижать интент - сообщение молча останется пустым.

## Стриминг, терминал и кодировки

Долгие скрипты могут стримить вывод, показывать статус-иконки и прогресс-бары через API `dass.tool.result` - UI
показывает их вживую. С `run-terminal: true` скрипт получает интерактивный терминал, прикреплённый к карточке, вместо
управляемого процесса: без таймаута и с чтением с клавиатуры.

Скрипты Python и Bash пишутся как UTF-8 без BOM, PowerShell - как UTF-8 **с** BOM (Windows PowerShell 5.1 читает
`.ps1` без BOM как ANSI), а преамбула Batch - чистый ASCII, чтобы кириллический аргумент выжил в любой кодовой
странице.
