# Начало работы

Добро пожаловать в **dASS** — десктопного ассистента на Avalonia UI и .NET 10.

## Что такое dASS?

dASS — это мощный ассистент на базе LLM с:

- Богатой расширяемой **системой тулов** (файловая система, веб, базы данных, скриптование и другое)
- **Многоагентной коллаборацией** со специализированными агентами
- **Семантической памятью** для фактов и эпизодических логов
- **Скриптовыми аддонами** - тулами, слэш-командами и prompt-контекстами на Lua, Python, Bash, PowerShell или
  Batch
- Встроенным **веб-чатом** для многопользовательского общения

## Первые шаги

1. Добавьте **API-ключ** в *Настройки → Модели*.
2. Создайте **новый чат** и выберите провайдера моделей.
3. Спросите ассистента о чём угодно — он сам воспользуется тулами при необходимости.

```markdown
# Пример markdown

- списки
- **жирный** и *курсив*
- `инлайн-код`
```
