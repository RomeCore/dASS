# Tools

Tools — это «руки» ассистента. Они позволяют модели действовать в системе, а не
только разговаривать.

## Категории тулов

| Категория | Примеры |
|---|---|
| Файловая система | чтение, запись, правка, поиск файлов и папок |
| Веб | загрузка URL, поиск в интернете, скачивание файлов |
| Базы данных | запросы к SQLite, PostgreSQL и SQL Server |
| Скриптование | запуск скриптов на Lua, Python, Bash, PowerShell и Batch |
| Память | сохранение и поиск фактов и логов |
| Математика | вычисление выражений, решение уравнений |
| Случайное | броски кубиков, случайные числа, GUID |

## Human-in-the-loop

Опасные тулы запрашивают **подтверждение** перед выполнением. В запросе показывается
превью того, что тул собирается сделать, — вы можете одобрить или отклонить.

> [!WARNING]
> Тулы, изменяющие или удаляющие файлы, всегда требуют подтверждения. Внимательно
> проверяйте дифф перед тем, как принять его.

См. также: [Скриптовые тулы](scriptable-tools.md), [Скриптование](scripting.md).
